# NoteShare-Database
NoteShare Database Project
NoteShare is a fully relational SQL database modeled after a music streaming application similar to Spotify or Apple Music. The system manages data about artists, albums, songs, features, playlists, and users, with a focus on playlist organization and user music preferences. The project demonstrates database normalization, referential integrity, and query optimization through structured SQL scripts and Power BI integration.

The repository includes:

Schema Script: Creates all tables, relationships, and inserts realistic seed data for artists, albums, songs, and playlists.

Analytical Queries: Demonstrates read and write operations such as data retrieval, aggregation, insertion, updates, and deletions.

Power BI Query: Combines multiple tables into a flattened analytical dataset for visualization and dashboard reporting.

Design Document: Explains the purpose, entities, relationships, and scope of the project, providing conceptual context.

The project illustrates an understanding of data modeling, SQL development, and data visualization workflow. It represents the kind of relational backend infrastructure a modern music application would rely on for managing content and user engagement
